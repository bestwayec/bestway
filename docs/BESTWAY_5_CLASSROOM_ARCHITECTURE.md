# BESTWAY 5.0 classroom architecture

The classroom roster reads open periods from `ClassroomEnrollment`. Each period records the student, group, dates, and source. Staff adds open a period, removals close one period, and an explicit transfer closes the specified source and opens the destination within one transaction. The legacy profile group remains a preference for existing clients. Group and learner row locks serialize writes and the partial unique constraint prevents duplicate open periods.

Web and Telegram share the same classroom invitation service. Staff issue a new random code with an expiration, optional capacity, and optional approval. The database keeps the digest and a rotation version. To copy the code or link after leaving the page, generate a replacement. Pending approvals are tied to the version. Revocation and rotation cancel the outstanding requests from the old version. Telegram accepts `/join CODE` followed by `/join CODE confirm` in a linked student's private chat. Existing standalone cohorts retain separate legacy access pending reconciliation.

Classroom exam access requires the recorded assignment launch, an existing explicit homework submission, or an actual supervised live session. A former learner's assigned result keeps its group context. Assignment and roster mutations use current group ownership. The student may grant and revoke read-only sharing of personal practice to an eligible current classroom teacher. A teacher accessing the result through that grant cannot grade it. Historical teacher assignment records, co-teaching authorization, account merging, and complete legacy roster conversion remain open.
