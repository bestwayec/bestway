# Redesign stage 1 — design system

- **before**: `../redesign-0/before/` (main `3b46c08`).
- **after**: this folder, same script (`scripts/e2e-local/redesign-screens.mjs`), plus `devui-*` (the `/dev/ui`
  component gallery, full page).

What changes on every screen: warm "paper" neutrals in light mode and a deeper, less blue dark mode;
radii from tokens (cards 14 px, controls 10 px); no coloured or glowing shadows; KPI tiles without coloured
icon squares (`StatTile`); 44 px inputs and selects with a 3:1 border. Layouts are unchanged in this stage.
