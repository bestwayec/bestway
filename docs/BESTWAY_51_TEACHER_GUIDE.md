# BESTWAY 5.1 teacher guide

1. **Assign**: Group → Classroom assignments → pick the published exam, set the deadline (Tashkent time), optional opening time, and **Exam timing**:
   * *Fixed closing time (supervised)* — everyone ends at the deadline; unfinished work is handed in by the server even if the browser is closed.
   * *Individual duration* — each student gets the full exam time after starting.
2. **Monitor**: open the assignment's **Results** link. Counts (eligible, not started, in progress, submitted, auto-submitted, awaiting grading, fully graded, not submitted) refresh every 20 s. Live Exam Guard alerts keep working as in 5.0.
3. **Grade Writing/Speaking** in the existing Assessment review (original essay, task image, original recording, optional transcript). AI suggestions are advisory; your confirmation is the final grade. Grading works with AI switched off.
4. **Results**: preliminary report when the exam closes; final report automatically after your last grade. Telegram: full ranked list privately to you; the classroom group gets totals only. Excel export uses the same data. *Resend Telegram report* asks for confirmation and never changes grades.
5. If Telegram is unavailable, the website Result Center and Excel remain authoritative.
