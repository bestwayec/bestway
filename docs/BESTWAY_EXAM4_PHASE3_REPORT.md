## Classroom calculation rules

- The report filters attempts by start date in the application's local timezone. A classroom assignment uses enrollment at assignment creation and explicit attempt links to establish eligibility. Without an assignment filter, participation uses current members and students with attributable attempts in the selected period.
- Started and submitted counts use distinct learners. A learner with a completed attempt in the filtered set counts as graded even if a separate attempt is pending. Completion divides eligible learners with a submission by eligible learners.
- Attendance averages each learner's recorded present (1), late (0.5) and absent (0) marks, then averages the available learner rates. Excused and missing marks are excluded. The report displays an unavailable value when there are no eligible marks.
- Score summaries select one eligible result per learner, exam and specification/scoring version and then average each learner's results within each scale. Ranking partitions use exam, version and scale. Equal scores receive the same rank. The next rank skips the positions occupied by the tie. The default is latest eligible result, with best eligible result as an explicit alternative.
- Objective accuracy divides correct responses by graded attempted responses. Blank answers are reported separately, and pending or unavailable evaluations are excluded. Incorrect-choice summaries require at least two distinct learners selecting the same authored option.
